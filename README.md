# Career Quest · NeonCode

Фронтенд платформы развития сотрудников для трека Halyk Bank / HackAlem.
Спокойный светлый интерфейс с зелёными акцентами, адаптированный для телефона и десктопа.

## Запуск

Требуется Node.js 20.9+ и npm. Из корня репозитория:

```sh
npm --prefix frontend ci && npm --prefix frontend run dev
```

Откройте http://localhost:3000. Для production: `npm --prefix frontend run build`, затем `npm --prefix frontend start`.

## Возможности

- Обзор сотрудника: карьерная цель, готовность и до трёх объяснимых рекомендаций.
- Траектория: требования целевой роли и грейда, критические навыки и текущий план.
- Каталог: поиск, фильтры, условия участия, запись на добровольные активности.
- Завершение активности в демо: пересчёт уровней с учётом gain / max_level.
- История: статусы и фильтрация, сохранение изменений в localStorage.
- HR: разрывы по навыкам, готовность команды и отсутствие завершений за 90 дней. Без публичного рейтинга.
- Импорт JSON профилей и CSV истории, включая проверочные профили жюри. Файлы проверяются и применяются вместе; ошибка не меняет текущие данные. Совпадающие ID обновляются.

Дата демо — **2026-10-01**, согласно README датасета. Имена и названия активностей сохранены в исходном английском виде; интерфейс — русский.

## Границы фронтенд-демо

Backend и LLM в репозитории отсутствуют. Подбор использует прозрачный многофакторный алгоритм, **не является AI-рекомендацией** и явно обозначен в интерфейсе. Учитываются целевая роль/грейд, критичность и прирост навыка, условия участия, история завершений/пропусков и длительность. Обязательные активности не рекомендуются. Исторические завершения после последней оценки применяются к профилю в хронологическом порядке.

Переключатель профиля и HR-экран предназначены для демонстрации на синтетических данных. Серверная авторизация и разграничение прав пока не реализованы. Данные поставляются в клиентском bundle. Не использовать для реальных персональных данных без backend, контроля доступа и замены локального хранения.

Запись и завершение изменяют только локальное состояние браузера; интеграции с LMS, календарём и сервером отсутствуют. Для сброса удалите ключ `career-quest-v1` из localStorage.

## Структура и интеграция

- `frontend/src/components/career-app.tsx` — интерфейс и сценарии демо.
- `frontend/src/lib/career.ts` — типы, расчёты, валидация и чтение CSV.
- `frontend/src/lib/dataset.json` — подготовленный синтетический датасет.
- `frontend/scripts/prepare-data.mjs` — воспроизводимая подготовка из `dataset/case_1/career_quest_dataset`.
- `frontend/tests/career.spec.ts` — расчёты и браузерные сценарии.

При подключении backend замените начальную загрузку и localStorage на авторизованный API, перенесите HR-данные за серверный контроль доступа, а функции recommendations / enroll / complete — на вызовы сервисов. Сохраните формат объяснения: разрыв навыка, требование цели, ожидаемый прирост и факторы истории.

## Проверки

```sh
cd frontend
npm run lint
npm run build
npx playwright install chromium
npm test
```

`npm run data:prepare` обновляет клиентский датасет после изменения стартовых файлов. `npm run format` форматирует исходники.

## Git

Рабочая ветка: `feature/frontend`. Интеграционная ветка: `dev`. Изменения разделяются на коммиты данных, интерфейса и проверок. Перед публикацией необходимо получить актуальную удалённую ветку и выполнить проверки; production-ветка `main` не обновляется без проверенной интеграции.
