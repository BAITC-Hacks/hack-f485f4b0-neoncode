# Career Quest backend

Стек: Python 3.12, FastAPI, Pydantic v2, SQLAlchemy 2.x, SQLite, pytest, uv, Docker.
Модульный монолит в backend/app/. Фронтенд (frontend/) не трогать.

Правила:

- Схемы API (app/schemas.py) и модели БД (app/models.py) не менять без явной просьбы.
- Рекомендации никогда не строятся по одному признаку (например, только самый слабый навык).
- Рост навыка: new = min(5, max(current, min(current + gain, max_level))). Навык никогда не понижается.
- LLM выбирает только из переданного списка событий; ответ валидируется, при ошибке или таймауте работает fallback-скоринг.
- Если LLM_API_KEY не задан, используется mock/fallback-режим, и это явно видно в ответе API (поле source).
- Датасет организаторов не отправлять во внешние сервисы, кроме LLM-вызовов рекомендаций, если это разрешено.
- Не выдумывать данные; synthetic fixtures помечать как synthetic.
- После изменений запускать pytest и ruff.
