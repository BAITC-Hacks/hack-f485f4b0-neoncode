# Synthetic fixtures

All records are synthetic, authored for local development. They are not derived
from organizer employee records. Identifiers use the `SYN_` prefix; JSON metadata,
individual records and the CSV `synthetic` column explicitly label the data.

Contents: 10 employees, 8 events, 15 skills, 8 role/grade requirements and 12 history
records. JSON envelopes and CSV columns follow the dataset format. The extra
`synthetic` marker is optional when loading other datasets.
