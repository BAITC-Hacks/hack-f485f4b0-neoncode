# Career Quest frontend

Стек: React + Vite + TypeScript, Tailwind, shadcn/ui, Recharts, TanStack Query.
Работать только во frontend/. backend/ не трогать.

Правила:

- Контракт API — backend/docs/openapi.json. Типы генерировать из него, поля не выдумывать и не переименовывать.
- Все запросы через один API-клиент. Заголовки X-Role (employee|hr) и X-Employee-Id ставит только он.
- Базовый URL через VITE_API_URL, по умолчанию /api.
- Роль в UI — только переключатель для демо. Права проверяет бэкенд, 401/403 показывать понятным сообщением.
- Никаких рейтингов, лидербордов и сравнения сотрудников между собой.
- У каждого экрана должны быть состояния loading / error / empty.
- Рекомендация может идти до 10 секунд: показывать скелетон, не блокировать страницу.
- После изменений запускать tsc --noEmit и lint.
